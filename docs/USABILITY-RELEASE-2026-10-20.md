# Guided workflow release

The part workspace now combines the existing guided sample/units/priority work with named local revisions, portable project transfer, original-geometry and camera views, two-orientation comparison, physical-case topology/confirmation gates, thermal and structural two-resolution sensitivity checks, and actual-STL wireframe views in PDF reports. Sensitivity comparisons carry run/candidate/input identity in JSON and PDF exports. Local revisions are explicit snapshots rather than automatic version control; save before changing parts. Export for durable backup.

The sample library includes a cube, overhanging bracket, thin-wall channel, hollow sleeve, and a mounting lug with bore, plus an intentionally open invalid STL. All are educational geometry, not actual aircraft engineering drawings. Category sources and limitations are in AEROSPACE-SAMPLE-PARTS.md. The mounting lug has a reproducible generator.

Verification: 22 numerical/data regressions and four Chromium workflow tests cover upload, both physical solvers and their mesh comparisons, field display, reports, local revision restoration, mobile topology blocking, and all example geometries. A manual visual review additionally identified and corrected edge-on initial framing of thin parts. PDF wireframes were rendered and inspected.

Limits: geometry screens run as preliminary calculations before dimensions are confirmed. Physical cases require confirmation and are blocked by audit topology blockers. Mesh edge size is not wall thickness; self-intersections and thin-feature resolution still need engineering review. Boundary overlays are schematic global planes, not user-picked surfaces. Two resolutions are not mesh independence. No new manufacturing physics or validation claim is introduced. Machine envelopes and physical material properties remain user inputs, not qualified vendor presets. Teammate usability acceptance, conforming meshing and arbitrary boundary selection remain future work.
